# Picky Guru

Knowledge is the core. A responsive, dependency-free static website with an original orbital-book SVG logo, animated hero, searchable topic cards, and three local calculation tools.

## Run
Open index.html directly, or serve the repository with any static HTTP server. No installation, API keys, analytics, or backend required.

## Models
- Bayesian update: a binary hypothesis posterior with explicit prior and likelihood inputs; impossible evidence is reported as undefined.
- Information content: -log2(p) for one event, not distribution entropy.
- Learning planner: minutes × days × weeks / 60; a time budget, not a mastery prediction.

## Publishing
Website files are in the repository root. To publish with GitHub Pages, select Settings > Pages > Deploy from a branch > main > / (root). A live deployment has not been verified by this commit. Expected address after successful activation: https://artur-su.github.io/picky-guru/

## Accessibility and privacy
Responsive layout, labelled controls, focus outlines, reduced-motion support, semantic landmarks, and local-only calculations. No external fonts, dependencies, or tracking. Browser-level visual and accessibility testing remains to be performed.

## Design
Original Picky Guru identity inspired by the emerald direction of Picky Hub and the futuristic orbital presentation of Artur's personal website. Existing repositories are unchanged.
